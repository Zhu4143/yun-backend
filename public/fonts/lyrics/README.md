# Lyric fonts

Locally hosted, unmodified Google Fonts WOFF2 subsets. Each family includes its SIL OFL 1.1 notice. Font CSS and Unicode subsets load only when selected. No Google Fonts runtime request.

See manifest.json for sources, sizes and SHA256 checksums. Refresh with PowerShell 7: pwsh -NoProfile -File tools/vendor-lyric-fonts.ps1
