# 主播放器上沿进度条与整卡入口

- 主播放器和沉浸播放器复用 `Timeline` 的 minimal 模式：闲置 1px 白线，鼠标/笔悬停或键盘聚焦时 3px，高潮点为 3px 白点，没有圆球。鼠标指针状态直接由 Pointer Events 判断，兼容主指针媒体查询不报告鼠标的预览环境。
- 主进度线铺到卡片上沿，左右留出圆角空间。44px 命中区域主要向上延伸，避免挡住卡片内的封面、标题和按钮；时间在悬停或聚焦时显示。
- 中间控制区移除了旧的第二行时间轴，五个按钮自然下移约 11px，居中于卡片。
- 背景入口使用单独的兄弟按钮，覆盖整个卡片；按钮和滑杆在更高层独立命中。不嵌套交互按钮，也不依赖父级点击冒泡来打开沉浸模式。保留键盘 Enter 和退出后的焦点恢复。
- 手机使用相同的可交互进度条，删除原先只能展示的移动端进度条，避免出现两条或无法拖动的情况。

验证：

- `npm.cmd run test:app`：81/81；定向 ESLint 通过；生产构建通过。
- 实际浏览器检查上沿位置、按钮下移、1px/3px 状态和无色块的透明输入层。
- 三处卡片空白采样均命中整卡入口；所有五个控制按钮、右侧按钮、音量滑杆均命中自身。
- 实际鼠标点击空白进入沉浸模式、点击上沿跳到 75.9 秒、播放暂停、方向键调整进度和音量、Enter 进入以及收起返回均通过；控件操作没有误触整卡入口。
- 375×812 手机视口无水平溢出，封面区域仍命中整卡入口，鼠标点击文字附近可进入沉浸模式；仅有一条可见进度滑杆。手机证据为浏览器视口验证。
- 原矿脉和歌词预设文件 SHA256 未变；主预览播放状态由用户保留，交互测试在独立页完成。
