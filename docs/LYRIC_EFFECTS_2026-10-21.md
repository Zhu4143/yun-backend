# 沉浸歌词效果与细线进度条

## 行为

- 右上角星光按钮打开歌词特效调节。桌面用左侧唱片区域放面板，右侧歌词继续预览；手机上方预览、下方调节。收起后恢复唱片。矿脉面板默认收起。
- 配色支持歌曲封面、自定义双色、渐变强度；支持辉光、重影距离和强度、叠色、三类系统字体、字号、字重和行距。
- 染色使用实际音频 currentTime，并在暂停、跳转、倍速、缓冲与双播放器交接后同步。当前歌词源提供逐句时间，句内扫色按相邻时间区间插值，不声称具有逐字演唱时间。
- 仅当前句产生字形效果层，20 次/秒更新 CSS 变量；不通过每帧 React state 驱动。隐藏、暂停及卸载后停止动画并释放监听。
- 歌词效果经独立 `/api/visuals/lyric-effects` GET/POST 接口和原子 JSON 存储保存。调节只预览，点击“保存歌词效果”才持久化；不写矿脉背景。
- 沉浸进度条闲置时 1px 白线，悬停、键盘聚焦或按压时 3px；高潮点为 3px 白点，保留点击跳转。没有圆球滑块，仍可拖动和使用键盘。音量滑杆不受影响。

## 验证

- `npm.cmd run test:app`：75/75，通过逐句时序、同时间翻译、最后一句、偏移、暂停、缓冲、跳转、媒体交接、监听清理、Unicode 字素与独立保存恢复等回归。
- 新增和修改的前端/存储模块通过定向 ESLint；前端生产构建通过。
- 实际内置浏览器验证：播放中染色、暂停后填色不变、控件即时改变 CSS、字体切换、Escape 收起面板、方向键调整进度、点击真实高潮白点。
- 1280×720 桌面与 375×812 手机视口检查无水平溢出，面板与播放控制不相互遮挡；手机证据是浏览器视口验证。
- 保存相关回归在临时目录运行；独立浏览器检查页未保存测试参数，未重置用户正在调节的主预览。
