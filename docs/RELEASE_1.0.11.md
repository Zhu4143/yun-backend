# 昀音乐 1.0.11

2026-10-22，Windows x64。

## 当前版本

- 默认入口切换为轻量音乐界面，保留原有果冻液态玻璃材质与日夜主题。
- 沉浸播放采用实体唱片、随封面取色的液态矿脉背景和可调歌词特效。
- 待播列表为右侧透明浮层，歌词同时显示，唱片及播放控制保持原位。
- 两种播放进度条逐帧读取真实媒体时钟，保留细白线、小副歌点和原生定位操作。
- 歌词支持逐渐扫色、多种叠加效果、12 个字体选项及风格分类匹配；9 款网页字体随包本地加载。
- 首次启动采用当前设计的视觉默认值，已有保存的设置继续优先使用。
- 收录音频连接恢复、切歌取消、启动加载和相关交互修复。

## 发布边界

- 当前源码通过 `npm.cmd run verify`，包括 lint、所有测试阶段、确定性会话 E2E 和生产构建。
- Windows 安装包由对应源码提交生成，并包含版本及提交标识。
- `.env`、账号 Cookie、聊天记忆、个人音乐库索引、私人封面、歌词库和本地模型权重不随本次源码快照或安装包分发；本机文件保留。
- 历史 Git 记录没有重写。独立原型和含账号信息的本地 QA 截图保留在本机。
- 本地音乐由使用者导入；在线曲目可用性由来源服务与账号权限决定。聊天、语音和桌面代理功能仍需配置各自服务，安装包不附带模型权重或 API 凭据。
- 窄屏布局有浏览器验证，未声称实体手机测试。安装包检查与校验值随 Release 提供。
