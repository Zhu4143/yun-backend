# 搜索去重与沉浸矿脉调节

搜索页隐藏顶部全局搜索，仅保留内容区的一个搜索框。其他页面继续使用顶部入口。输入内容共用同一状态，侧栏搜索入口和 Ctrl K 均会聚焦当前搜索框。

沉浸模式右上角新增调节图标。打开后，调节区替换歌词位置；实体唱片、播放控制、原有果冻玻璃继续保留。四组参数共 21 项：流动、光影、颜色、换歌。只登记外层面板为一个玻璃表面，内部控件不叠加折射。

拖动滑块立即预览。现有渲染器直接更新参数，保持一个 canvas、30FPS、95 万内部像素上限。流动速度采用连续积分，调整速度不会把已流过的时间按新速度重算而突然跳变。

点击“保存效果”后通过 `/api/visuals/immersive-background` 原子写入 `server/data/immersive-background.json`，含版本、参数和保存时间。该机器上打开的 Chrome / 内置预览使用同一后端保存记录，在进入沉浸模式时读取。预览不自动写盘，恢复默认也需要再次点击保存。文件及备份已忽略，不随代码提交。

验证：

- 真实浏览器搜索页只有 1 个搜索表单和 1 个搜索输入框，Ctrl K 聚焦及提交返回结果正常。
- 流速由 0.016 调到 0.017 时，后端仍保留 0.016，保存时间为空；点击保存后后端记录 0.017，刷新并重新打开恢复为 0.017。测试结束恢复原始默认参数并保存，未替用户挑选新效果。
- 保存配置能跨新的 store 实例恢复；无保存记录时读取默认效果不创建文件；无效参数有边界，无效保存请求不覆盖原记录。
- 1280×720 与 390×844 浏览器布局检查；窄屏无横向溢出，保存按钮底部约 609px，处于视口内。没有实体手机验证。
- 设置页保持 1 个沉浸场景 canvas、原版 `liquid-ore` 外层材质。Esc 收起调节区恢复歌词，焦点回到调节按钮。
- 68 项界面与持久化测试、修改文件 ESLint、生产构建全部 exit 0；浏览器未记录 error。沙箱首次拒绝临时文件原子 rename，随后在正常本地权限下完整重跑并通过。
