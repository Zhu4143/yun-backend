# 布局编辑器第一版 — 2026-10-06

## 范围

按已确认的第一阶段接入底部播放器、聊天卡片、声音面板。支持拖动、八方向缩放、吸附、多选移动/排列、精确尺寸输入、撤销重做、保存、取消、恢复默认和 JSON 迁移。没有修改 TTS、网易云或歌曲队列业务。

### 范围限制

这是已有 DOM 的布局编辑器，支持持续 Flex 排版，但不新建或重新挂接 DOM 节点，也不改歌曲文字内容。虚拟歌曲行的位置 / 行高仍由列表业务管理；内部文字、封面和按钮样式统一应用于同类行。不同项目需要适配注册卡片与内部结构路径。
