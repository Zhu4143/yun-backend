# 连续播放进度验证 · 2026-10-21

## 改动

- 主播放条、沉浸播放共用 `timelinePainter.js`，每个显示帧直接读取当前歌曲的媒体时钟，只更新进度线的 CSS 变量，不产生每帧 React 渲染。
- 白色已播放部分通过 `scaleX` 连续推进；保留细白线、悬停变粗、小白色副歌点和原生范围输入的键盘／触摸定位。
- 暂停和结束时停止动画帧；后台页面和沉浸模式背后的主播放条暂停绘制。冻结的音频时钟不会被外推成虚假进度。
- `crossfadeTimeline.getMedia()` 提供与当前显示歌曲一致的媒体源：淡入开始后读取目标音轨，提交后读取引擎当前音轨。
