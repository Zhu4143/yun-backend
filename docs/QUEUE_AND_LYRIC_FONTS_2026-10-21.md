# 透明贴边队列与风格字体

## 待播列表

- 桌面列表改为固定在屏幕右侧的 320–390px 抽屉，顶底贴边，播放控制留在左侧。手机抽屉贴右覆盖内容区，保留页头和底部播放控制。
- 黑色来自沉浸渲染器默认的 72% 深色玻璃染色：DOM 的 `.glass-finish` 在复现时是隐藏的，队列没有指定 `--glass-tint-opacity`，因此采用深色默认值。只将该面板设为 0 后，背景纹理透出；对照截图保存在 `before.png` 和 `tint-zero.png`。
- 使用原来的 Liquid Ore 光学通道，保留折射和边缘反光。也修正了不启用光学通道时的深色 CSS 底色。
- 光学注册原先用 `parseFloat(radius) || 26`，把合法的 0px 方角当成默认圆角。现保留零值，并有回归用例。
- 手机隐藏唱片时，WebGL 也读取槽位可见性，避免唱片透到队列下方。
- 夜间主题原有 range 背景覆盖了无滑块进度条的透明输入层；修正选择器优先级后，44px 点击区域保持透明，实际可见轨道仍是 1px 白线。

## 字体

共 12 种选择：3 种系统字形和 9 款实际下载的 Google Fonts 字体。

| 分类 | 默认字体 |
| --- | --- |
| 古风 / 国风 | Ma Shan Zheng 毛笔楷体 |
| Phonk / 暗黑 | UnifrakturCook 哥特；中文搭配站酷庆科黄油 |
| 电子 / 赛博 | Orbitron；中文搭配站酷庆科黄油 |
| 摇滚 / 说唱 | Bebas Neue；中文搭配站酷庆科黄油 |
| 民谣 / 独立 | Long Cang 手写行草 |
| 轻快 / 动漫 | ZCOOL KuaiLe |
| 古典 / 爵士 | Cormorant Garamond；中文搭配 ZCOOL XiaoWei |
| 抒情 / 流行 | ZCOOL XiaoWei |

- 自动分类优先使用已有 genre/style/tags 等标签，之后使用曲名、歌手及专辑关键词。面板显示判断来源；不明确的歌曲保留默认字体。
- 可手动修正当前歌曲分类、修改 8 类风格的字体映射，或切换为固定字体。与既有“保存歌词效果”一起保存；未保存的预览不写磁盘。
- 字体目录 `public/fonts/lyrics/`，保留原始 WOFF2、每款 OFL 授权、源 URL、校验值与清单。重下工具为 `tools/vendor-lyric-fonts.ps1`（PowerShell 7）。只部署网页字体，不安装系统字体。
- 当前选中的字体才插入本地样式，CJK 保留 Unicode 分片，按歌词用字加载；运行时无 Google Fonts 请求。切换字体时当前歌词重新居中，手动阅读状态仍被保留。
- 项目关闭了默认 public 目录复制。`vite.config.js` 现按字体 manifest 将字体、CSS 和授权加入原有资源白名单；构建后已确认 9 款字体的 470 个 WOFF2 文件全部存在。后端已有 `font/woff2` MIME 支持，Electron 从 dist 静态目录读取。
